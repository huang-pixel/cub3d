Parser architecture:

parse_file()
│
├── open .cub file
│
├── read lines one by one
│
│   ├── empty line?
│   │      └── handle it
│   │
│   ├── configuration line?
│   │      ├── NO → parse north texture
│   │      ├── SO → parse south texture
│   │      ├── WE → parse west texture
│   │      ├── EA → parse east texture
│   │      ├── F  → parse floor color
│   │      └── C  → parse ceiling color
│   │
│   └── map line? (there should not be empty lines inside the map line)
│          └── start collecting map
│
├── finish reading map
│
├── check all 6 identifiers were found
│
├── validate map
│
└── success

parse_map() high level flow:

function parse_map(map_lines, game):

    1. validate map lines (characters, empty lines)
    2. build rectangular grid from map_lines
    3. store grid, width, height in game->map
    4. find player position and direction
    5. check that map is closed (flood-fill or border checks)
    6. if anything fails → print error, return 1
    7. otherwise → return
