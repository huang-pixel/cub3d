Parser architecture:

parse_file()
│
├── open .cub file
│
├── read lines one by one
│
│   ├── empty line?
│   │      └── handle it
│   │
│   ├── configuration line?
│   │      ├── NO → parse north texture
│   │      ├── SO → parse south texture
│   │      ├── WE → parse west texture
│   │      ├── EA → parse east texture
│   │      ├── F  → parse floor color
│   │      └── C  → parse ceiling color
│   │
│   └── map line? (there should not be empty lines inside the map line)
│          └── start collecting map
│
├── finish reading map
│
├── check all 6 identifiers were found
│
├── validate map
│
└── success
